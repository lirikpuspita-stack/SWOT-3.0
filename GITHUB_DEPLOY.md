# GitHub Pages Deployment

## Cara paling sederhana
1. Buat repository baru di GitHub.
2. Upload semua file dari folder ini ke root repository.
3. Pastikan `index.html` berada di root.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`.
7. Klik **Save**.

Aplikasi tidak membutuhkan backend atau database. Data disimpan di `localStorage` browser pengguna.
